Push-to-talk always records until you let go.

                  Screenshot
                  
    Only for models that can read images.
    
                
    
                
    
                  
                
    
              
    
              
    
                Context goes to your configured provider. With a hosted provider, window titles,
                clipboard text and screenshots leave your machine. Clipboard entries older than
                5 minutes are not shared, and entries a password manager marks as concealed are
                skipped. Setting the entries to 0 clears what was collected. Refine last and Retry
                resend only what these settings allow now, and nothing if you switched provider.

    Model guide
    
              
    
                Pick a local model that fits your machine. Every tier works with
                Ollama: run ollama pull <model>, then set it in
                the  section.
              
    
            
    

            
    
              Privacy first.
              Local models keep every word on your machine: no accounts, no cloud costs, no data
              retention. Hosted providers (OpenAI, Anthropic, OpenRouter…) are convenient but send your
              transcriptions and prompts to external servers. For a voice coding tool we recommend a
              local model whenever your hardware supports it.

              Not sure which tier you are? Quick check
              
    
                RAM: Windows → Task Manager → Performance → Memory.
                macOS → Apple menu → About This Mac → Memory.
                Linux → free -h
    
                GPU VRAM: Windows → Task Manager → Performance → GPU.
                macOS → About This Mac → Graphics. Linux → nvidia-smi or rocm-smi
    
                Rule of thumb: the model's file size must fit in VRAM for GPU inference,
                or in RAM for CPU inference (leave about 2 GB free for the OS).
